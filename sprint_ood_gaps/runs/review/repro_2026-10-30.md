# Reproduction check of main-slide numbers (30 Oct 2026, ood-gaps-cb)

Method: a fresh clone of github.com/LittleMeHere/ood-gaps (commit d12244f) in a scratch directory. Each script was run inside the clone with the project's venv, CPU only, no API or judge calls, outputs written inside the clone (never to the real `runs/`). Missing inputs were recorded, then brought in from the real project one file at a time (copied if under 300 MB, else a read-only link). Regenerated outputs were diffed against the saved ones in the real project. Runner and logs: session scratchpad `repro/run_repro.py`, `repro_log.jsonl`.

## Does not run from a clean checkout

The repo holds code, designs and run summaries, not the large inputs, so no script that reads per-prompt data runs from a clean checkout. Inputs each one needed:
- `runs/negatives/index/` (traffic and Dolci text, hashes, embeddings): `gap_heuristic.py`, `neg_wildchat_builtin.py`, `topic_split_analyse.py`, `gap_taxonomy_blindspots.py`.
- `external/hf/` (Sohan's labels and Dolci data from HF `detectood/ood`, private): `neg_wildchat_builtin.py`, `gap_taxonomy_blindspots.py`.
- `runs/topic_split/<partition>/{split.json, split.parquet, queries.parquet, topics.parquet, groups.json, candidates_b.parquet}`: `topic_split_analyse.py`, `detector_improve_analyse.py`.
- `runs/gap_taxonomy/{labels,reviews,name_fit,sole,resample}.jsonl`, `facets/{sample,tags,sole}.jsonl`, `emergent/{clusters.npz,names.jsonl}`, `blindspots/prompts.parquet`: the gap-taxonomy scripts.
- `runs/fix_loop/data/eval.jsonl`, `out/eval_base|eval_lora/*/rollouts.jsonl`, `out/train/build_stats.json`: `fix_loop_analysis.py`.
- `runs/rare_gaps/{topics.csv, one_sided.npz, labels/}`, `runs/robust/qwen_one_sided.npz`: `robust_analyse.py`.
- `runs/acts_dolci/shard*.jsonl`, `runs/triggers/dolci_labelled/`, and the raw LMSYS/WildChat parquet files in the local Hugging Face cache (`~/.cache/huggingface/hub`).

Silent failure modes (worse than a missing-file error, because the script finishes with a wrong number):
- Glob or `exists()` reads that return nothing: `gap_taxonomy_analyse.py` (labels and reviews read as empty), `gap_facets.py` (kappa None), `review_part15_null20.py` (16 features instead of 37), `topic_split_analyse.py` and `detector_improve_analyse.py` (topic bootstrap instead of group bootstrap; Mahalanobis rows dropped), `fix_loop_analysis.py` (one line dropped), `gap_taxonomy_blindspots.py` (no conversations found, so multi-turn would be 0%).
- Scripts that call an LLM when a cache file is absent: `gap_grouping_recovery.py` (Sonnet, if `group_kinds.json` is missing); `gap_removal_judge.py` always calls both judges.

No audited script hardcodes an absolute path. None needs an uncommitted script.

## Mismatches

None among the numbers re-run: every re-run main-slide number matches its saved value. Not re-run: removal 3b (CPU hours), the index build, and two numbers computed inline in reviews (step-8 grouped +0.006; fix2 0.72-0.76, recomputed by Sole).

## Silent failures fixed (30 Oct, after this check)

Each script now stops with a message naming the missing input instead of finishing with a wrong number; behaviour with all inputs present is unchanged.
- `gap_facets.py analyse`: requires `facets/sole.jsonl` (was: kappa None).
- `review_part15_null20.py`: stops if `facets/summary.json` has no Sole kappas (was: 16 task-only features instead of 37).
- `fix_loop_analysis.py`: requires `out/train/build_stats.json` (was: dropped the line).
- `trig_scan.py`: requires files in `runs/triggers/dolci_labelled/` (was: division by zero).
- `gap_taxonomy_analyse.py`: requires each of `reviews, labels, name_fit, sole, resample .jsonl` (was: read as empty).
- `topic_split_analyse.py`, `detector_improve_analyse.py`: grouped partitions require `groups.json` (was: fell back to a topic bootstrap).
- `gap_grouping_recovery.py`: if `group_kinds.json` is missing, stops unless `ALLOW_JUDGE_CALLS=1` (was: called Sonnet).
- `gap_taxonomy_blindspots.py`: stops if no LMSYS or WildChat parquet files are found in the HF cache (was: multi-turn silently 0).
Confirmation: all eight re-run in the clone with inputs present give the same outputs as before the change (the only differences are the same `improve_summary.json` interval ends and the same dict-order line as in the check above); three failure paths tested by removing the input (gap_facets, fix_loop_analysis, gap_grouping_recovery), each stops with its message. Pre-change copies: session scratchpad `scripts_before_loud/`.
